# Sentiment Analysis

This folder will contain `sentiment_analyzer.py` — the second stage of the NLP pipeline.

**Responsibilities (Phase 6):**
- Use VADER (Valence Aware Dictionary and sEntiment Reasoner) to score feedback text.
- Return a compound score between -1.0 (most negative) and +1.0 (most positive).
- Map score to a label: Positive, Neutral, or Negative.

This module will be created in Phase 6.
