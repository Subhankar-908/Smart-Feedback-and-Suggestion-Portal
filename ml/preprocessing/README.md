# Preprocessing

This folder will contain `text_cleaner.py` — the first stage of the NLP pipeline.

**Responsibilities (Phase 5):**
- Convert text to lowercase
- Remove punctuation and special characters
- Tokenize text into individual words
- Remove stop words (e.g., "the", "is", "a")
- Apply lemmatization to normalize word forms

This module will be created in Phase 5.
