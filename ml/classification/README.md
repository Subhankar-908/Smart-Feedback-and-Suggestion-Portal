# Category Classification

This folder will contain `category_classifier.py` — the third stage of the NLP pipeline.

**Responsibilities (Phase 7):**
- Use keyword matching to classify feedback into one of the following categories:
  - Teaching Pace
  - Lab Facilities
  - Syllabus Coverage
  - Infrastructure
  - Other (default fallback)
- The classification logic is kept in a separate module so it can later be upgraded to an ML model.

This module will be created in Phase 7.
